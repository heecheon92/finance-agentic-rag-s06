출처는 `results/agentic.json`과 `results/roi.json`이다. 토큰·재검색·지연은 실행 기록이며, 비용은 `src/finrag/eval/cost.py`의 단가를 적용한 추정치다. 캐시 할인을 반영한 40문항 API 비용은 mini $0.18488, nano $0.06397로 mini가 더 크다(개별 호출이 아닌 모델별 합계). 로컬 검색의 API 요금은 없지만 서버비는 든다.

## 3. 월 비용

월 11,000건에서 API는 $0.006221 × 1,400 × 11,000 ≈ **95,803원**, CPU 서버는 **300,000원**, 합계는 **395,803원**이다. 표시용 8.71원이 아닌 달러 비용으로 계산한 뒤 반올림했다. 개발·운영 인력, 보안·법무 검토 등 미산정 비용은 포함하지 않았다.

## 4. 외부 API vs 내부망 GPU — 3년 TCO

TCO는 기간 내 구매·운영 비용의 합계다. 아래는 현재 비용 모델에 포함된 항목만 비교한다.

| 안 | 3년 비용 | 계산 및 특성 |
| --- | --- | --- |
| 외부 API | 14,248,908원 | 395,803 × 36; GPU 초기 투자 없이 모델 교체 용이, 외부 전송 데이터 검토 필요 |
| 내부망 GPU | 53,800,000원 | 25,000,000 + 6,000,000 × 3 + 300,000 × 36; 내부 처리 가능, 모델 운영·품질 검증 필요 |

일 500건에서는 API 안이 **39,551,092원 저렴**하다. 공통 서버 고정비를 상쇄하면 손익분기점은 43,000,000 ÷ (36 × 22 × 8.7094) ≈ **6,234건/일**이다. 기존 계산기의 고정비 비례 확대 오류를 수정해 JSON에도 반영했다. 이보다 적으면 API, 많으면 GPU가 비용상 유리하나, 동일 품질·처리 용량은 검증되지 않았고 증설 비용은 제외했다.

## 5. 절감과 순 효과

월 11,000 × 3분 ÷ 60 = **550시간**, 인건비 환산 가치는 **13,750,000원**이다. API·서버 비용을 빼면 월 순 효과 추정은 **13,354,197원**이다(`results/roi.json`: `monthly`). 실제 현금 절감이나 이익 증가가 아니라 다른 업무에 활용할 수 있는 시간의 가치이며, 추가 검토 시간은 아직 차감하지 않았다.

## 6. 이 숫자를 믿기 전에

1. **3분 절감은 가정이다.** 도입 전후 업무 시간을 측정하고, 오답·근거 확인까지 포함한 순 절감 시간으로 바꿔야 한다.
2. **오거절률은 7.89%다.** 답변 가능한 38문항 중 3문항 기준이며, 전체 질문 비율이나 오답률이 아니다. 재처리·검토 비용을 반영해야 한다.
3. **단가·규모 가정은 변한다.** 2026-10-08 단가표와 고정 환율을 사용했다. 질문 길이·재검색·캐시·GPU 증설에 따라 비용과 손익분기점이 달라진다.
